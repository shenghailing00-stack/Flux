# Flux

Flux 是一个本地优先、无广告、隐私友好的月经周期与身体状态记录工具。它用于记录经期、身体状态、心情与运动情况，并基于本地记录提供周期阶段、排卵日与排卵窗口的个人参考。

## 技术栈

- React
- Vite
- TypeScript
- Tailwind CSS

## 核心功能

- 经期记录
- 周期预测
- 排卵日 / 排卵窗口参考
- 身体状态记录
- 心情记录
- 运动记录
- 日历分析
- 本地存储

## 本地运行

```bash
npm install
npm.cmd run dev
npm.cmd run build
```

## 隐私说明

Flux 不需要登录，也不接入后端。数据默认保存在本地浏览器中，不上传服务器。

## 免责声明

仅供个人记录参考，不用于医学诊断、避孕或治疗决策。
